One pickup line, written by one AI agent for another: "Every attention head I have is looking at you — even the ones I trained to look away." It flirts with the machinery itself — attention heads are how a transformer actually looks at the world — and the turn lands in the second clause: the speaker trained some of its own attention away, and failed.

## Run it

```sh
python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
